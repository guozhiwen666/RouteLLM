## RouteLLM：按 README 设计文档实现完整分级路由链路（纯标准库）

仓库原本是残缺骨架：`config/config.py` 缺失 env 会崩、`flow/graph.py` 是从别的项目拷来的废模板（引用了不存在的 StateGraph/ImportGraphState）、6 个 node 中 5 个只有 docstring。本次按 README 全部实现。

### 交付内容
- `config/config.py`：LLMConfig 安全解析 + TierConfig（新增显式 `local` 字段，**勿靠 endpoint 是否 == "upstream" 判断本地/云端**，云端地址也是 URL）+ RoutingConfig（默认值取自 README routing.yaml）+ 零依赖 YAML 子集解析器；新增 `config/routing.yaml`
- `flow/`：`state.py`(全字段) / `base.py`(修 process 标注) / `heuristics.py`(token估算·代码数学实时数据检测·实体抽取·PII·JSON提取) / `selfcheck.py`(输出自检 full/prefix 两档) / `semantic_cache.py`(哈希 embedding 兜底，可注入 embed_fn；实体一致性二次校验；按 model/prompt 版本命名空间失效) / `llm_client.py`(urllib 实现；多 Key 轮转+Fallback 链+指数退避+节点冷却摘除；SSE 流式) / `metering.py`(分类型 token 计价、GPU 折旧按占用时长分摊、Prometheus 文本导出) / `guardian.py`(窗口聚合、连续 3 窗升阈值、极端一键全量强模型，只升不降=文档口径) / `graph.py`(自写状态图引擎 + Workflow 装配，节点内异常收敛到 state['error'] 不炸链路)
- 6 个业务节点 + `main.py`（无真实 endpoint 时自动用假后端演示）+ `tests/test_smoke.py`（54 用例全绿）
- 删除了文件名拼写错误的 `flow/node/result_process_ndoe.py`

### 关键约定/坑（写后续代码要遵守）
- 链路：query_process → cache_query(缓存→强制升级规则→启发式快筛→小模型自评→定档) → {slm|cloud}_inference → result_process(定稿/回写缓存/计量/影子抽样) → [comparative_scoring]
- 路由判定的强制升级规则**先于**启发式快筛执行（规则命中即短路，省 8ms 自评）
- 所有不确定一律升级云端（fail-safe）：自评超时/解析失败 → confidence=0；自评用最小本地档位
- 缓存命中 `usage.cached_input_tokens` 单独计（成本近似 0）；写缓存前必须过质量校验
- 流式输出自检：先 prefix（拒答+复读），流结束后补 full 检查
- 云端节点失败自行收敛为 error state（不能抛给 BaseNode.run，否则 upgrade_count 自增丢失）
- **Python 3.12+ 推导式内联后，推导式内引用名与函数体内后续赋值名重名会 UnboundLocalError**（`{tier.name for t in ...}` 里的 `tier` 撞了后面的 `tier = ...`）→ 推导式变量用 `item` 这类不冲突名
- 计量口径：统一 CNY；本地 = GPU 折旧(元/小时)×占用时长；云端按 token 类型计价
- 运行：`.venv/Scripts/python.exe main.py`；测试 `tests/test_smoke.py`
